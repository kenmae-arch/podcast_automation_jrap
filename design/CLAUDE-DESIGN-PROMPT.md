# Claude Design に貼るプロンプト

> 使い方: claude.ai/design で新規プロジェクトを作り、**DESIGN.md / CONTENTS.md / 番組カバー(docs/cover-v2.jpg)/ 各シリーズのアートワーク(docs/art/shinkoiwa.jpg, docs/art/malltape.jpg)** を添付した上で、下のプロンプトを貼る。

---

日本語ラップの名盤を1話1曲で深掘り解説するポッドキャスト「日本語ラップ アルバム全曲解説(J-RAP DEEP DIVE)」の公式サイトを作ります。まずは HOME のヒーロー(ファーストビュー)のデザインを固めたいので、**方向性の異なる3案**を作ってください。

添付ファイルの役割:
- **DESIGN.md** … デザイン仕様書。§9 に3案それぞれの方向指定(A: AVYSS寄りの白黒ブルータリズム / B: FNMNL寄りのダークメディア / C: シリーズ着せ替え型)があります。この3方向で1案ずつ作ってください。カラー・書体・モーションは §2〜§8 のトークンに従ってください
- **CONTENTS.md** … サイトに載せる事実。ヒーローに入れる要素・文言(§2 HERO)はここにあるものだけを使い、事実を創作しないでください
- **画像** … cover-v2.jpg は番組カバー、shinkoiwa.jpg は連載中シリーズ『新小岩』、malltape.jpg は完結シリーズ『Mall Tape』のアートワークです

各案の要件:
1. ヒーローはフルビューポート(またはそれに近い高さ)のHTMLプロトタイプとして作り、直下に続くセクション(連載中シリーズの棚 = CONTENTS.md §4)の冒頭が少し覗く状態まで作ってください
2. 見出しの日本語タイポグラフィが主役です。書体は DESIGN.md §3 の指定(Noto Serif JP / Noto Sans JP / IBM Plex Mono)の範囲で
3. ヒーローのアニメーションは要検討事項です。各案に「その案の世界観に合うモーションコンセプト」を1つ実装し(CSS/最小限のJSのみ、ライブラリ不可)、`prefers-reduced-motion` では静止するようにしてください。動きの意図を案の説明文として言語化してください
4. モバイル(375px)とデスクトップ(1280px)の両方で成立させてください。日本語見出しが単語の途中で改行されないように
5. 3案は並べて比較するので、それぞれに短い案名と「狙い/どんな読者に刺さるか/リスク」を3行で添えてください

背景情報: 姉妹番組(海外編)のサイトは「生成りの紙×墨×赤、欧文セリフ主導の明るいエディトリアル調」です。今回はその姉妹番組と並べたときに明確に別の顔になること(黒基調・日本語書体主導)が最重要の差別化要件です。詳細は DESIGN.md §1 を参照してください。
