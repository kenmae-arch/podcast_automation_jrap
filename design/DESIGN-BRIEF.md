# DESIGN-BRIEF.md — 日本語ラップ アルバム全曲解説 トンマナ設計書

Claude Design に渡すデザインブリーフ。内容(事実)は CONTENTS.md を優先。

## 1. 番組の性格 = デザインの根拠

1. **批評・解説の長尺番組**。パーティーの熱ではなく「夜に1曲をじっくり聴き込む」温度。読ませる editorial の佇まいが本筋。
2. **シーズン=アルバム、1話=1曲**の連載構造。『Mall Tape』(ネオンの夜のモール)→『新小岩』(夕焼けの商店街と筆文字)とシリーズごとに世界観が一変する。**基調はモノトーンに抑え、シリーズのアクセント1色とアートワークだけが色を持つ**構造にすると、どのシリーズが来ても破綻しない。
3. **日本語タイポグラフィが主役**。「新小岩」「上昇の合図」「土手と夕焼けの詩学」— タイトルがすべて強い日本語。海外編との最大の差別化はここ。

## 2. 姉妹番組(海外編)との差別化 — 「やらないこと」

姉妹番組サイトのトンマナ(web/src/styles/tokens.css より):
生成り紙 #f2efe8 × 墨 #151515 × シグナル赤 #d84b32、Inter + Instrument Serif、
明るい紙面のプリント・エディトリアル調。

本サイトはこれと**並べたとき明確に別の顔**にする:

- ❌ 生成りの明るい紙面 → ⭕ **黒/墨ベースのダークトーン**
- ❌ 欧文セリフ(Instrument Serif)主導 → ⭕ **日本語書体(明朝・太ゴシック)主導**
- ❌ シグナル赤の固定アクセント → ⭕ **シリーズごとに着せ替わるアクセント1色**
- 現行仮サイトの「暗紫+ネオンピンク」も卒業する(海外のクラブ風に見えるため)

## 3. 参考サイト(トーンの座標)

- **FNMNL** https://fnmnl.tv/ — 日本のヒップホップメディアの標準トンマナ。黒基調・サムネイル主導・情報密度。「シーンの内側にいる」温度感。
- **AVYSS magazine** https://avyss-magazine.com/ — モノクロ基調のブルータリズム。装飾ではなく余白と文字組の緊張感でアンダーグラウンド感を出す。
- 構造の参考: **Dissect** https://dissectpodcast.com/ (シーズン=アルバムの棚見せ)

この2つ(FNMNL / AVYSS)の間のどこに立つかを、ヒーロー3案で探る(§6)。

## 4. デザイントークンの方向(たたき台)

- **ベース**: 墨黒 #121212 前後 / 文字 #f0ede6 前後(真っ黒・真っ白は避け、わずかに温度を残す)
- **アクセント(シリーズ着せ替え)**: 『新小岩』= 夕焼けオレンジ系、『Mall Tape』= ネオンシアン系。ページルートの CSS 変数 `--series-accent` で切り替える設計(姉妹番組の `--album-accent` と同じ仕組み)
- **書体**: 見出し = Noto Serif JP(明朝・太め)/ 本文 = Noto Sans JP / 英字ラベル・番号 = モノスペース系(IBM Plex Mono 等)。Google Fonts で読める範囲に限定
- **質感**: わずかな粒子ノイズ(紙とアスファルトの中間)。角丸はほぼ使わない。罫線は細く
- **禁じ手**: グラデーション多用、ネオン発光の多色使い、丸ゴシック、絵文字

## 5. アニメーション方針

- 実装先は **GitHub Pages の静的サイト(vanilla HTML/CSS/JS)**。ライブラリ前提の演出は不可。CSS scroll-driven animations / IntersectionObserver / CSS keyframes で成立する範囲
- 方向性: 「文字が主役の控えめなキネティック・タイポ」。1字ずつ立ち上がる見出し、墨が滲むようなフェード、緩いパララックス、テキストティッカー等
- **必須**: `prefers-reduced-motion` で移動・stagger を止める / JS 無効でも本文が読める(opacity:0 で放置しない)

## 6. ヒーロー3案の方向指定(Claude Design への発注内容)

| 案 | 座標 | 概要 |
|---|---|---|
| A | AVYSS 寄り | **白黒ブルータリズム**。巨大な明朝の日本語見出し(縦書き併用可)、細罫、粒子ノイズ。色はほぼ無し。アニメは文字の立ち上がり・にじみ |
| B | FNMNL 寄り | **ダークメディア**。シリーズアートワーク(夕焼けの新小岩)を大きく使い、情報密度高め。アクセント1色。アニメはアートワークの緩いパララックス+ティッカー |
| C | 中間・シリーズ着せ替え型 | 墨黒ベース+`--series-accent`(今は夕焼けオレンジ)。ヒーローが「現在連載中: ZORN『新小岩』残り2話」を看板として掲げる。シリーズが替わると色とアートだけが替わる。アニメは音の波形/カウンターなど「連載が進んでいる」ことを見せる動き |

各案とも、ヒーローに入る要素は CONTENTS.md §5-1 の通り(番組名・J-RAP DEEP DIVE・リード文・連載中シリーズ導線)。

## 7. 品質基準(姉妹番組 HANDOFF.md から継承)

- 320〜1920px で横スクロールを出さない
- 操作要素は 44×44px 以上
- `h1` は1ページ1つ、見出し階層を守る
- **日本語見出しを単語の途中で改行しない**
- `prefers-reduced-motion` 対応、`aria-hidden` 内にフォーカス可能要素を置かない
- 欠損データは非表示(「不明」「TBD」を画面に出さない)
