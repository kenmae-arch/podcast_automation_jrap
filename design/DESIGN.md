# Visual Design System (DESIGN.md)

本ファイルは、AIエージェントがUIコード(HTML, CSS, React, など)を生成する際に参照するデザイン仕様書です。UIを構築する際は、必ずこのルールに従ってください。対になる CONTENTS.md が中身(事実)を担います。

## 1. トーン&マナー
* **ブランドイメージ:** 墨黒のエディトリアル。「夜に1曲をじっくり聴き込む」温度の批評誌。日本語タイポグラフィが主役。AVYSS magazine(モノクロ・ブルータリズム)と FNMNL(黒基調のストリートメディア)の間に立つ
* **コアバリュー:** 読ませる批評であること。シリーズ(=アルバム)ごとに世界観が着せ替わっても破綻しないこと
* **最重要の差別化要件:** 姉妹番組(海外編)サイトは「生成り紙 `#f2efe8` × 墨 `#151515` × シグナル赤 `#d84b32`、欧文セリフ(Instrument Serif)主導の明るいプリント・エディトリアル調」。本サイトはこれと並べたとき明確に別の顔にする — **黒基調・日本語書体主導**。現行仮サイトの「暗紫+ネオンピンク」も卒業する
* **禁じ手:** グラデーション多用、ネオン発光の多色使い、丸ゴシック、絵文字、明るい紙面

## 2. カラーパレット (Colors)
指定された役割(トークン)に応じて、以下のカラーコードを厳密に使用してください。基調はモノトーンに抑え、**色を持つのはシリーズアクセントとアートワークだけ**にします。
* **Background (背景):** `#121212`(墨黒。真っ黒 #000 は使わない)
* **Surface (カード・パネル):** `#1a1918`
* **Text Main (本文テキスト):** `#f0ede6`(わずかに温度のある白)
* **Text Muted (薄いテキスト):** `#a29d94`
* **Border (境界線):** `#33312d`(細罫。強調時 `#5a564f`)
* **Primary (シリーズアクセント):** CSS変数 `--series-accent` で管理し、シリーズごとに着せ替える
  * 『新小岩』(連載中・現在の既定値): `#e8703a`(夕焼けオレンジ)
  * 『Mall Tape』: `#4fd8d0`(ネオンシアン)
  * アクセント上の文字色: `--series-accent-contrast: #121212`
* **質感:** ごく薄い粒子ノイズ(紙とアスファルトの中間)を背景に敷いてよい。opacity 3〜5%程度

## 3. タイポグラフィ (Typography)
* **見出し(日本語):** `"Noto Serif JP", "Hiragino Mincho ProN", serif` — 太めのウェイト(700〜900)。明朝が本サイトの顔
* **本文(日本語):** `"Noto Sans JP", "Hiragino Sans", sans-serif`
* **英数字ラベル・番号・日付:** `"IBM Plex Mono", "SFMono-Regular", monospace` — 「EP 11」「2026.08.13」等のメタ情報に使用
* フォントは Google Fonts で読める範囲に限定すること
* **ベースフォントサイズ:** `16px` (1rem)
* **ディスプレイ(HEROの主見出し):** `clamp(2.75rem, 1.4rem + 5.8vw, 6rem)`, `line-height: 1.15`, 明朝・太字
* **見出し 1 (h1):** `clamp(2.25rem, 1.3rem + 4vw, 4.5rem)`, `line-height: 1.2`, 明朝・太字
* **見出し 2 (h2):** `clamp(1.5rem, 1.2rem + 1.5vw, 2.5rem)`, `line-height: 1.3`, 明朝・太字
* **本文 (p):** `1rem` (16px), `line-height: 1.85`(日本語長文のため広め)
* **ラベル (小):** `0.75rem`, `letter-spacing: 0.2em`, モノスペース・大文字
* 縦書き(`writing-mode: vertical-rl`)をアクセントとして使ってよい(シリーズ名・キッカー等)
* **日本語見出しを単語の途中で改行しない**(`<wbr>` や改行位置の制御で守る)

## 4. スペースとレイアウト (Spacing)
余白や配置は、以下の4pxベースのグリッドシステムを基準に設定してください。
* `spacing-1`(最小の余白): `8px`
* `spacing-2`(標準的な余白): `16px`
* `spacing-3`(要素間の余白): `32px`
* `spacing-4`(セクション間の余白): `64px`
* `spacing-5`(大きなセクション間): `96px`
* **コンテナ最大幅:** `1440px` / 本文の読み幅: `680px`
* **レイアウト方式:** CSS Flexbox または CSS Grid を優先的に使用すること

## 5. コンポーネントスタイル (Components)
* **ボタン (Button):**
  * 角丸 (border-radius): `2px`(ほぼスクエア。丸くしない)
  * パディング: 縦 `12px`, 横 `24px`(最小タップ領域 44×44px を確保)
  * 通常: `1px solid` の枠線+透過背景 / 主要CTA: `--series-accent` の塗り
  * シャドウ: `none`
  * ホバー時のエフェクト: 枠線ボタンは `--series-accent` の塗りに反転。`transform` は使わないか最小限
* **カード (Card):**
  * 背景: `#1a1918`
  * 角丸 (border-radius): `0`(スクエア)
  * 境界線: `1px solid #33312d`
  * 影 (box-shadow): `none`(罫線で区切る)
* **audio プレーヤー:** ブラウザ標準の `<audio controls>` を使用してよいが、置き場はカード下部に統一する
* **罫線:** セクションやリストの区切りは細い水平線(`1px`)を基本にする

## 6. レスポンシブ振る舞い (Responsive)
* **モバイルファースト**で設計すること
* **ブレイクポイント:**
  * スマホ (Mobile): `~ 639px`
  * タブレット (Tablet): `640px ~ 1023px`
  * デスクトップ (Desktop): `1024px ~`
* 320〜1920px のどの幅でも横スクロールを出さないこと

## 7. アクセシビリティ (Accessibility)
* すべてのテキストは、背景色とのコントラスト比を `4.5:1` 以上にすること(`--series-accent` を文字色に使う場合は特に検証する)
* 画像には必ず `alt` 属性を記述すること
* すべての操作要素は `44×44px` 以上
* `h1` は1ページ1つ。見出しは h1 → h2 → h3 の階層を守る
* `prefers-reduced-motion` で移動・stagger・smooth scroll を止めること
* JS 無効でも本文が読めること(`opacity: 0` のまま放置しない。`html.has-js` が付いたときだけ隠す方式を推奨)
* 欠損データは非表示にする(「不明」「TBD」を画面に出さない)

## 8. モーション (Motion)
* 実装先は **GitHub Pages の静的サイト(vanilla HTML/CSS/JS)**。アニメーションライブラリは使用不可。CSS keyframes / CSS scroll-driven animations / IntersectionObserver で成立する範囲に限定
* 方向性: 「文字が主役の控えめなキネティック・タイポ」— 1字ずつ立ち上がる見出し、墨が滲むようなフェード、緩いパララックス、テキストティッカー等
* **時間・イージングのトークン:**
  * `--duration-fast: 140ms` / `--duration-base: 240ms` / `--duration-slow: 520ms` / `--duration-ambient: 1200ms`
  * `--ease-out: cubic-bezier(0.22, 1, 0.36, 1)` / `--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1)`

## 9. HEROの3案(今回の発注範囲)
方向性の異なる3案を作ること。各案に入る要素は CONTENTS.md §2 の通り。

| 案 | 座標 | 概要 |
| --- | --- | --- |
| A | AVYSS寄り | **白黒ブルータリズム**。巨大な明朝の日本語見出し(縦書き併用可)、細罫、粒子ノイズ。色はほぼ無し。アニメは文字の立ち上がり・にじみ |
| B | FNMNL寄り | **ダークメディア**。シリーズアートワーク(夕焼けの新小岩)を大きく使い、情報密度高め。アクセント1色。アニメはアートワークの緩いパララックス+ティッカー |
| C | 中間・シリーズ着せ替え型 | 墨黒ベース+`--series-accent`(現在は夕焼けオレンジ)。ヒーローが「連載中: ZORN『新小岩』#11まで公開」を看板として掲げ、シリーズが替わると色とアートだけが替わる。アニメは音の波形や話数カウンターなど「連載が進んでいる」ことを見せる動き |

## 10. エージェントプロンプトガイド (Agent Prompt)
AIエージェントへの指示です。コードを生成する際は、以下のルールを遵守してください。
1. 上記のトークン(変数名またはカラーコード)をハードコードせず、可能な限りCSS変数を用いて表現してください。シリーズ固有色は必ず `--series-accent` 経由で参照してください
2. 日本語が不自然にならないよう、文字間隔(`letter-spacing`)や行間を適切に調整してください。見出しの `letter-spacing` は控えめ(0〜0.06em)、英字ラベルは広め(0.2em前後)
3. 事実(番組名・シリーズ情報・話数・文言)は CONTENTS.md にあるものだけを使い、創作しないでください。欠損項目は非表示にしてください
4. 未知のデザイン要素を生成する場合は、事前にユーザーに質問するか、このデザインシステムに準拠した形で提案してください
