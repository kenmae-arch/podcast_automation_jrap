# Visual Design System (DESIGN.md)

本ファイルは、AIエージェントがUIコード(HTML, CSS, React, など)を生成する際に参照するデザイン仕様書です。UIを構築する際は、必ずこのルールに従ってください。対になる CONTENTS.md が中身(事実)を担います。

> **状態: 実装済み。** Claude Design のヒーロー3案から「白盤・墨一色」(案A系統)を採用し、
> `docs/` 配下に実装した。トークンの唯一の実体は `docs/site-assets/site.css` の `:root`。
> 本ファイルはその転記であり、値を変えるときは両方を同時に直すこと。
> **2026-08-14 の確定変更**: 当初案の「墨黒ベース + シリーズ着せ替えアクセント」は破棄し、
> **紙白ベース・UIから彩色を全廃**(色を持つのはアートワークのみ)に変更した。§2・§3 は改訂済み。

## 1. トーン&マナー
* **ブランドイメージ:** 紙白 × 墨のモノクロ・エディトリアル。「1曲をじっくり聴き込む」温度の批評誌。日本語の明朝タイポグラフィが主役。AVYSS magazine(モノクロ・ブルータリズム)寄りに立ち、装飾ではなく余白と文字組の緊張感で見せる
* **コアバリュー:** 読ませる批評であること。シリーズ(=アルバム)ごとに世界観が変わっても破綻しないこと。**UIを無彩に保つことで、どのアートワークが来ても喧嘩しない**
* **最重要の差別化要件:** 姉妹番組(海外編)サイトは「生成り紙 `#f2efe8` × 墨 `#151515` × シグナル赤 `#d84b32`、欧文セリフ(Instrument Serif)主導」。本サイトはこれと並べたとき明確に別の顔にする — **クールな紙白・日本語明朝主導・無彩UI(固定アクセント色を持たない)**
* **禁じ手:** グラデーション多用、ネオン発光、丸ゴシック、絵文字、UIへの彩色

## 2. カラーパレット (Colors)
指定された役割(トークン)に応じて、以下のカラーコードを厳密に使用してください。UIは無彩で統一し、**色を持つのはアートワークだけ**です。
* **Background (背景 `--paper`):** `#f7f7f5`(クールな紙白)
* **Surface (カード・パネル `--surface`):** `#ffffff`
* **Text Main (本文テキスト `--ink-text`):** `#26221e`(墨。真っ黒 #000 は使わない)
* **Text Muted (薄いテキスト `--muted`):** `#6f6a61`(紙白に対し 5.0:1)
* **Border (境界線 `--line`):** `#ddd9d0` / 強調時 `--line-strong`: `#b5b0a5`
* **袋文字のストローク `--stroke`:** `#dcd8ce`
* **アクセント色は持たない。** 主要CTA・進行中タグは墨のベタ塗りで表す
* **質感:** 粒子ノイズ(インラインSVGの feTurbulence)を opacity 4% で敷く。ヒーロー背面は墨のにじみ(WebGL、フォールバックは radial-gradient 3層)

## 3. タイポグラフィ (Typography)
* **見出し(日本語) `--font-mincho`:** `"Shippori Mincho B1", "Hiragino Mincho ProN", "Yu Mincho", serif` — 600/700/800。明朝が本サイトの顔
* **本文(日本語) `--font-sans`:** `"Zen Kaku Gothic New", "Hiragino Sans", "Yu Gothic", sans-serif` — 400/500/700
* **英数字ラベル・番号・日付 `--font-mono`:** `"Space Mono", "SFMono-Regular", Consolas, monospace` — 「SERIES 02」「2026.08.13」等のメタ情報に使用
* フォントは Google Fonts で読める範囲に限定すること
* **ベースフォントサイズ:** `16px` (1rem)
* **ディスプレイ(HEROの主見出し):** `clamp(2.75rem, 1.4rem + 5.8vw, 6rem)`, `line-height: 1.15`, 明朝・太字
* **見出し 1 (h1・下層ページ):** `clamp(2rem, 1.3rem + 3vw, 3.75rem)`, `line-height: 1.2`, 明朝・太字
* **見出し 2 (h2):** `clamp(1.5rem, 1.2rem + 1.5vw, 2.5rem)`, `line-height: 1.3`, 明朝・太字
* **本文 (p):** `1rem` (16px), `line-height: 1.85`(日本語長文のため広め)
* **ラベル (小):** `0.75rem`, `letter-spacing: 0.2em`, モノスペース・大文字
* 縦書き(`writing-mode: vertical-rl`)をアクセントとして使ってよい(シリーズ名・キッカー等)
* **日本語見出しを単語の途中で改行しない**(`<wbr>` や改行位置の制御で守る)

## 4. スペースとレイアウト (Spacing)
余白や配置は、以下の4pxベースのグリッドシステムを基準に設定してください。
* `spacing-1`(最小の余白): `8px`
* `spacing-2`(標準的な余白): `16px`
* `spacing-3`(要素間の余白): `32px`
* `spacing-4`(セクション間の余白): `64px`
* `spacing-5`(大きなセクション間): `96px`
* **コンテナ最大幅:** `1440px` / 本文の読み幅: `680px`
* **レイアウト方式:** CSS Flexbox または CSS Grid を優先的に使用すること

## 5. コンポーネントスタイル (Components)
* **ボタン (Button):**
  * 角丸 (border-radius): `2px`(ほぼスクエア。丸くしない)
  * パディング: 縦 `12px`, 横 `24px`(最小タップ領域 44×44px を確保)
  * 主要CTA(`.btn`): 墨のベタ塗り × 紙白の文字 / 副次(`.btn--ghost`): `1px solid --line-strong` の枠線 + 透過背景
  * シャドウ: `none`
  * ホバー: 主要CTA は `opacity: .85`。枠線ボタンは墨のベタ塗りに反転。`transform` は使わない
* **カード (Card):**
  * 背景: `--surface`(`#ffffff`)
  * 角丸 (border-radius): `0`(スクエア)
  * 境界線: `1px solid --line`
  * 影 (box-shadow): `none`(罫線で区切る)
* **エピソード行:** `<details>` / `<summary>` で、開くと要旨と `<audio controls preload="none">` が出る。
  音声は開いたときに初めて読み込む(一覧を開いただけで15本のmp3を取りに行かせない)
* **audio プレーヤー:** ブラウザ標準の `<audio controls>` を使う。見た目は環境依存なので `filter: grayscale(1)` で紙面に馴染ませるに留める
* **罫線:** セクションやリストの区切りは細い水平線(`1px`)を基本にする

## 6. レスポンシブ振る舞い (Responsive)
* **モバイルファースト**で設計すること
* **ブレイクポイント:**
  * スマホ (Mobile): `~ 639px`
  * タブレット (Tablet): `640px ~ 1023px`
  * デスクトップ (Desktop): `1024px ~`
* 320〜1920px のどの幅でも横スクロールを出さないこと

## 7. アクセシビリティ (Accessibility)
* すべてのテキストは、背景色とのコントラスト比を `4.5:1` 以上にすること(`--muted` は紙白に対し 5.0:1 で合格。墨煙の上に小さな文字を置くときはスクリムで紙を戻す)
* 画像には必ず `alt` 属性を記述すること
* すべての操作要素は `44×44px` 以上
* `h1` は1ページ1つ。見出しは h1 → h2 → h3 の階層を守る
* `prefers-reduced-motion` で移動・stagger・smooth scroll を止めること
* JS 無効でも本文が読めること(`opacity: 0` のまま放置しない。`html.has-js` が付いたときだけ隠す方式を推奨)
* 欠損データは非表示にする(「不明」「TBD」を画面に出さない)

## 8. モーション (Motion)
* 実装先は **GitHub Pages の静的サイト(vanilla HTML/CSS/JS)**。アニメーションライブラリは使用不可。CSS keyframes / CSS scroll-driven animations / IntersectionObserver で成立する範囲に限定
* 方向性: 「文字が主役の控えめなキネティック・タイポ」— 1字ずつ立ち上がる見出し、墨が滲むようなフェード、緩いパララックス、テキストティッカー等
* **時間・イージングのトークン:**
  * `--duration-fast: 140ms` / `--duration-base: 240ms` / `--duration-slow: 520ms` / `--duration-ambient: 1200ms`
  * `--ease-out: cubic-bezier(0.22, 1, 0.36, 1)` / `--ease-in-out: cubic-bezier(0.65, 0, 0.35, 1)`

## 9. HERO(確定仕様)
採用案は「白盤・墨一色」。実装は `docs/index.html` + `docs/site-assets/site.css` の `.hero` 系。

* 高さ `min-height: 86svh`。直下に SERIES 棚の冒頭が覗く
* 左カラム: キッカー → h1「名盤を、1曲ずつ。」(明朝 800)→ サブコピー → CTA **1つだけ**(「最新話を聴く」→ #episodes)。RSS導線はナビとフッターに置き、ヒーローにボタンは置かない
* 右カラム: 縦組みの袋文字(装飾・640px未満では非表示)/ アートワークカード / 看板プレート(「NOW RUNNING」+ 連載中の一文 + 話数カウンター + 波形)
* 最下部: キーワードバー(JAPANESE HIP HOP / ALBUM GUIDE / TRACK BY TRACK / DEEP DIVE PODCAST)
* 背面: WebGL の墨煙(可視時のみコンテキストを持ち、外れたら破棄)。非対応環境は radial-gradient にフォールバック
* ヘッダー帯だけは紙のスクリムを敷いて、小さな文字のコントラストを確保する

### 下層ページ
ヒーローの代わりに `.page-head`(パンくず + h1 + リード + 粒子ノイズ)を置き、以降は同じトークンで組む。
シリーズ詳細だけは `.series-hero`(アートワーク + 話数カウンター + 波形 + 進捗バー)を持つ。

## 10. エージェントプロンプトガイド (Agent Prompt)
AIエージェントへの指示です。コードを生成する際は、以下のルールを遵守してください。
1. 上記のトークン(変数名またはカラーコード)をハードコードせず、必ず `docs/site-assets/site.css` の CSS変数を参照してください
2. 日本語が不自然にならないよう、文字間隔(`letter-spacing`)や行間を適切に調整してください。見出しの `letter-spacing` は控えめ(0〜0.06em)、英字ラベルは広め(0.2em前後)
3. 事実(番組名・シリーズ情報・話数・文言)は CONTENTS.md にあるものだけを使い、創作しないでください。欠損項目は非表示にしてください
4. 未知のデザイン要素を生成する場合は、事前にユーザーに質問するか、このデザインシステムに準拠した形で提案してください
5. **本文や一覧などの主要コンテンツを、スクロール演出(`.reveal`)で隠さないでください。** 演出が発火しなかったときに読めなくなります。`.reveal` は見出しや装飾ブロックに限って使います
6. `<img>` に `width`/`height` 属性を書くときは、CSS 側で `height: auto` も指定してください。指定しないと属性値が `aspect-ratio` に勝って画像が伸びます
