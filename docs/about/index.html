この番組について

日本語ラップの名盤を、1シリーズ = 1アルバム、1話 = 1曲の形式でたどる解説ポッドキャストです。

編成

1つのシリーズで1枚のアルバムを扱い、1話につき1曲を解説します。曲順どおりに頭から進むので、アルバムを聴きながら並走することも、通しで聴いてから振り返ることもできます。

1話は4,000〜6,000字(およそ10〜15分)の長尺です。制作背景、リリックが扱っているテーマ、そしてその曲がアルバムの中で果たしている役割を、腰を据えて掘り下げます。

歌詞の扱い

歌詞の朗読・引用は行いません。批評・解説を目的とした番組であり、楽曲そのものは各配信サービスで聴いていただくことを前提にしています。楽曲の権利は各権利者に帰属します。

事実と解釈を混ぜない

リリース情報や制作陣といった事実と、番組としての読みは、はっきり分けて話します。編集上の解釈には「このシリーズでは〜と捉えます」の形を使い、事実として断定しません。

裏付けの取れない情報は扱いません。とくに個別トラックの制作クレジットは公開情報が乏しいことが多く、その場合は「公開情報が少ない」ことも含めてそのまま伝えます。

制作について

台本は各回ごとに書き起こし、音声は読み上げ合成で制作しています。固有名詞の読み違いを防ぐため、音声化の前に読みのチェックを通しています。
